# Онлайн кітапхана жүйесі (Library System)

PHP және MySQL негізінде жасалатын веб-қосымша. Пайдаланушылар кітаптар каталогын қарап, іздеп, кітап қарызға алу сұранысын жібере алады; әкімші (admin) кітаптар мен қарыздарды басқарады.

> Жоба күйі: **8-апта — жоспарлау кезеңі** (жобалау құжаттары дайын, код келесі аптадан басталады).

## Мақсаты
Шағын кітапхананың кітаптарын есепке алуды және оқырмандарға кітапты онлайн іздеп, қарызға алуды цифрландыру.

## Негізгі мүмкіндіктер
- Тіркелу, кіру, шығу (парольдер `password_hash()` арқылы сақталады)
- Кітаптар каталогы: қосу, көру, өңдеу, жою (CRUD)
- Кітапты атауы/авторы бойынша іздеу, жанр және жыл бойынша сүзу, сұрыптау, пагинация
- Кітапты қарызға алу және қайтару (оқырман өз қарыздарын көреді)
- Рөлдер: `user` және `admin`
- Қауіпсіздік: prepared statements (PDO), `htmlspecialchars()`, сессияларды қорғау, серверлік валидация

## Технологиялар
PHP 8, MySQL, PDO, HTML5, CSS3, JavaScript, Git/GitHub. Хостинг: InfinityFree.
